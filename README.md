# Планировщик — чертёж квартиры и дома

Продвинутое веб-приложение для создания чертежей планировки квартиры или дома.
**Стек:** Python + Flask + HTML5 Canvas (чистый JavaScript, без фреймворков).

## Возможности

### Инструменты рисования
- **Стены** — рисование с привязкой к сетке и узлам, регулируемая толщина
- **Двери** — с дугой открывания, переключение стороны открывания
- **Окна** — с двойной линией остекления
- **Комнаты / пол** — многоугольные зоны с автоматическим расчётом площади
- **Разделение стены** — разбить стену на две в точке клика
- **Линейка / размеры** — выносные размерные линии со значениями в метрах
- **Текст** — подписи помещений и заметок
- **Заметки** — стикеры на чертеже

### Электрика и освещение
- **Розетки** (одинарные, двойные, TV, интернет, электрощиток)
- **Выключатели** (одинарные, двойные)
- **Светильники** (потолочные, люстры, точечные, бра, торшеры, LED-лента)

### Мебель (40+ объектов)
- **Гостиная:** диваны, кресла, журнальный стол, ТВ-тумба, ТВ на стене, камин
- **Спальня:** кровати (1- и 2-спальные), шкафы, шкаф-купе, тумбы, письменный стол, книжный шкаф
- **Кухня:** угловая кухня, обеденный стол, стулья, кухонный остров, барные стулья, холодильник, плита, духовка, микроволновка, мойка, посудомойка, вытяжка
- **Санузел:** унитаз, биде, ванна, душевая кабина, раковина, стиральная машина, сушильная машина, бойлер, водонагреватель
- **Кабинет:** рабочий стол, офисное кресло
- **Разное:** лестница, батарея, машиноместо, бильярд, пианино, сейф, растения, лампы

### Просмотр
- **2D вид** — классический плоский чертёж с сеткой
- **3D вид** — псевдо-изометрическая проекция с extrude стен и мебели по высоте потолка
- Зум колесом мыши (с фокусом на курсоре), панорамирование (пробел / средняя кнопка / инструмент «рука»)
- Сетка с малыми и крупными линиями, оси координат

### Управление проектами
- **Сохранение** на сервер (локальная БД JSON-файлов)
- **Экспорт в JSON** — скачать проект как файл для бэкапа/переноса
- **Импорт из JSON** — загрузить ранее сохранённый проект
- **Экспорт PNG** — растровое изображение высокого качества (2x)
- **Экспорт SVG** — векторный формат для печати/редактирования
- **Шаблоны** — готовые планировки (студия 28 м², 1-к 40 м², 2-к 60 м², дом 100 м²)
- **Библиотека проектов** — список сохранённых с превью

### Калькулятор материалов
Автоматический расчёт по текущему чертежу:
- Площадь пола, периметр стен, площадь стен (с/без проёмов)
- Количество дверей и окон
- Напольные покрытия: ламинат (упаковки), линолеум, плитка, подложка
- Стены: обои (рулоны), краска (кг), штукатурка, грунтовка
- Потолок: краска, натяжной потолок, грунтовка
- Прочее: плинтус напольный/потолочный, кабель-канал, счётчики розеток/светильников/мебели
- Печать расчёта в PDF через диалог печати браузера

### Слои
Переключение видимости: сетка, комнаты, стены, двери/окна, мебель, текст/размеры, электрика/свет.

### Прочее
- **Undo/Redo** (до 80 шагов), горячие клавиши Ctrl+Z / Ctrl+Y
- **Привязка** к сетке, концам стен, серединам стен
- **Свойства элемента:** длина, толщина, угол, цвет, координаты, поворот, размер
- **Статистика** в реальном времени: площадь стен, общая площадь, периметр
- **Тёмная тема** интерфейса, адаптивная вёрстка

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `V` | Выбрать |
| `W` | Стена |
| `D` | Дверь |
| `N` | Окно |
| `R` | Комната |
| `T` | Текст |
| `M` | Линейка / размер |
| `S` | Разделить стену |
| `O` | Розетка |
| `L` | Светильник |
| `E` | Ластик |
| `H` | Панорамирование |
| `Space` (удерживать) | Временное панорамирование |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / Повторить |
| `Ctrl+S` | Сохранить проект |
| `Delete` | Удалить выбранный элемент |
| `[` / `]` | Повернуть мебель на ±5° |
| `Enter` | Завершить рисование стены/комнаты |
| `Esc` | Отменить текущее действие |
| Колесо мыши | Зум |
| Двойной клик | Замкнуть комнату / завершить стену |

## Установка и запуск

### Требования
- Python 3.8+
- Flask (`pip install flask`)

### Запуск
```bash
cd floorplanner
pip install -r requirements.txt
python app.py
```

Приложение откроется на **http://localhost:5050**

### Структура проекта
```
floorplanner/
├── app.py                 # Flask-сервер: API save/load/list/delete
├── requirements.txt       # зависимости (flask)
├── data/                  # сохранённые проекты (JSON-файлы, создаётся автоматически)
├── templates/
│   └── index.html         # главный шаблон (toolbar, canvas, панели, модалки)
└── static/
    ├── css/
    │   └── editor.css     # стили (тёмная тема, адаптивность)
    └── js/
        ├── furniture.js   # библиотека мебели (40+ объектов с SVG-иконками)
        └── editor.js      # ядро редактора (canvas, инструменты, экспорт, калькулятор, 3D)
```

## API

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/` | Главная страница редактора |
| `GET` | `/api/plans` | Список сохранённых проектов |
| `POST` | `/api/plans` | Сохранить/обновить проект (body = JSON) |
| `GET` | `/api/plans/<id>` | Загрузить проект по ID |
| `DELETE` | `/api/plans/<id>` | Удалить проект |
| `GET` | `/api/health` | Проверка состояния сервиса |
